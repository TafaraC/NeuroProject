Merged review of Dorrell et al. (2023): LaTeX source and generated inputs.
  main.tex                the review (six rubric sections, references, appendix, NeurIPS checklist via checklist.tex)
  checklist.tex           NeurIPS checklist answers for the reproduction code
  ccn.sty                 course style file, unmodified
  numbers_numpy.tex       generated from numpy_impl/review/tables/numbers.tex (do not edit by hand)
  numbers_extra.tex       generated by make_review_numbers.py (do not edit by hand)
  tables/                 generated LaTeX tables copied from numpy_impl (sigma_table, ablation_table, sensitivity)
  figures/                PNG figures used in the appendix (norm_target_montage.png is drawn by make_figures.py)
  make_review_numbers.py  rebuilds numbers_numpy.tex, numbers_extra.tex and tables/ from the saved result files
  make_figures.py         redraws figures/norm_target_montage.png from the saved parameters of four runs
Build:  python make_review_numbers.py   (optional: needs only the standard library)
        pdflatex main && pdflatex main
The folder is self-contained and can be uploaded to Overleaf as it is.
