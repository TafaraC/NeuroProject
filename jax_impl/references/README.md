# Reference material

- Paper: Dorrell et al. (2023), *Actionable Neural Representations: Grid Cells from Minimal Constraints*.
  https://arxiv.org/abs/2209.15563
- Authors' implementation: https://github.com/WilburDoz/ICLR_Actionable_Reps
- JAX installation guidance: https://docs.jax.dev/en/latest/installation.html

The supplied paper, assignment brief, and review-template archive remain at the
repository root. Keep reading notes and any further literature here.

The environment follows the authors' JAX approach but uses current packages;
it is not a recreation of their original 2023 software environment. Their code
may need API adaptations. Record the upstream commit and attribution before
reusing code. No upstream code has been copied into this repository during setup.
